# YouTube PiP Subtitles

Chrome extension (Manifest V3) that opens YouTube videos and Shorts in a floating **Document Picture-in-Picture** window with a live, synced **subtitle overlay** — so you can keep watching with captions while working in another window.

Native video PiP cannot render custom caption overlays; the Document PiP API (Chrome 116+) can, and that's what this extension uses. The `<video>` element is moved into the PiP window, and a caption box is rendered on top of it, synced to `video.currentTime`.

## Features

- 🎬 Works on both **watch pages** and **Shorts**
- 💬 Synced subtitles from YouTube's own caption tracks (srv3 format)
- 🌐 Picks your UI language track, prefers human-made captions over auto-generated (ASR)
- 🅰️ Adjustable font size (10–40px) and optional subtitle background — applied live
- ⌨️ Keyboard shortcut: **Ctrl+Shift+P** (⌘+Shift+P on Mac)
- ♻️ Restores the video to its original spot when the PiP window closes

## Install (unpacked)

1. Clone or download this folder.
2. Open `chrome://extensions`.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select this folder.

## Usage

1. Open any YouTube video or Short.
2. Click the extension icon → **Open PiP window** (or press Ctrl+Shift+P).
3. A floating window appears with the video + subtitle overlay.
4. Close the PiP window to snap the video back into the page.

If the video has no captions, the window still works — you just won't see the subtitle box.

## Files

| File | Purpose |
| --- | --- |
| `manifest.json` | MV3 config: permissions, shortcut, content script |
| `background.js` | Service worker: routing, shortcut, MAIN-world player-response probe |
| `content.js` | Video detection, caption fetch/parse, PiP window + overlay |
| `popup.html` / `popup.js` | Toolbar UI with settings |
| `icons/` | Generated by `scripts/gen-icons.js` (dependency-free) |

## Troubleshooting

- **"Not a YouTube tab"** — navigate to youtube.com before toggling.
- **No subtitles** — the video may lack captions, or YouTube changed its player response shape. Open the PiP from a video where native captions play correctly.
- **Button does nothing after reloading the extension** — refresh the YouTube tab so the updated content script is injected.
- **Chrome version** — Document PiP requires Chrome/Edge 116+.

## Notes

- Caption text is fetched with your existing YouTube cookies (`credentials: 'include'`) directly from the track's `baseUrl`; nothing is sent to third parties.
- The extension only requests YouTube host permissions.
